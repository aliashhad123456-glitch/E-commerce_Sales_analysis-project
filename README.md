#**E-commerce Sales & Profitability Analysis | SQL, Python, Power BI, Excel**
- Analyzed 2,500+ synthetic e-commerce order-line records using SQL and Python to evaluate revenue, profit, margins, customer segments, product performance, and regional trends.
- Built an interactive Power BI dashboard with KPI measures, time intelligence, and slicers to surface product profitability, discount impact, and sales trends.
- Translated findings into business recommendations for pricing, discount strategy, and product/region prioritization.
Performed end-to-end data analysis on an e-commerce dataset using MySQL, Python (Pandas, NumPy, Matplotlib, Seaborn) and Power BI (DAX). Focused on data cleaning, exploratory data analysis, KPI development, and interactive business intelligence dashboards.
